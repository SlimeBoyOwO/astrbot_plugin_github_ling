## 卡片自定义样式修改说明

| 想改什么                                               | 位置                                                                                                           |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| 版式尺寸（宽度、左栏宽、圆角、内外边距）               | `card_render.py` 顶部 `WIDTH` / `LEFT_W` / `LEFT_W_PAIR` / `MARGIN` / `INNER` / `RADIUS`                       |
| 配色（米白背景、毛玻璃透明度、品牌青蓝、各事件语义色） | `card_render.py` 顶部 `BG_TOP` / `BG_BOTTOM` / `PANEL_ALPHA` / `BORDER` / `BRAND` / `TEXT_*` / `ACTION_COLORS` |
| 整体绘制顺序                                           | `render_card()`：背景 → 投影 → 毛玻璃 → 左栏 → 右栏 → 角标                                                     |
| 左栏（头像、作者名、类型、操作胶囊）                   | `render_card()` 里的 `# --- 左栏` 段，头像绘制在内部函数 `_avatar()`                                           |
| 顶部图标 / 猫爪角标                                    | `_draw_icon()`、`_paw_badge()`                                                                                 |
| 字号                                                   | `render_card()` 里 `# --- 字号` 那几行 `card.font(...)`                                                        |
| 正文排版（标题、列表、引用、代码块、行内代码）         | `rich_body.py`：`RichLayout._style()` 管字体颜色，`layout()` 管块级样式                                        |
| 纯文本兜底长啥样                                       | `cards.py`                                                                                                     |

改完用 `python tools/preview_cards.py --render` 直接出图看效果，`--avatar 图片路径` 可以预览头像。
