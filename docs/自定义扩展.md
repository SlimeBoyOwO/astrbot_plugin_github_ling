## 卡片自定义样式修改说明

| 想改什么 | 位置 |
| --- | --- |
| 版式尺寸（宽度、左栏宽、圆角、内外边距） | `render/card.py` 顶部 `WIDTH` / `LEFT_W` / `LEFT_W_PAIR` / `MARGIN` / `INNER` / `RADIUS` |
| 配色（米白背景、毛玻璃透明度、品牌青蓝、各事件语义色） | `render/card.py` 顶部 `BG_TOP` / `BG_BOTTOM` / `PANEL_ALPHA` / `BORDER` / `BRAND` / `TEXT_*` / `ACTION_COLORS` |
| 整体绘制顺序 | `render/card.py` 的 `render_card()`：背景 → 投影 → 毛玻璃 → 左栏 → 右栏 → 角标 |
| 左栏（头像、作者名、类型、操作胶囊） | `render_card()` 里的 `# --- 左栏` 段，头像绘制在内部函数 `_avatar()` |
| 顶部图标 / 猫爪角标 | `_draw_icon()`、`_paw_badge()` |
| 字号 | `render_card()` 里 `# --- 字号` 那几行 `card.font(...)` |
| 正文排版（标题、列表、引用、代码块、行内代码） | `render/rich_body.py`：`RichLayout._style()` 管字体颜色，`layout()` 管块级样式 |
| 纯文本兜底长啥样 | `render/markdown.py` |
| 通知里显示哪些字段 | `render/markdown.py` 的 `render_event()` |

改完用 `python tools/preview_cards.py --render` 直接出图看效果，`--avatar 图片路径` 可以预览头像。

## 自动发 Issue 的提示词

| 想改什么 | 位置 |
| --- | --- |
| 模型的写作要求 / JSON 输出格式 | `issue/agent.py` 顶部的 `SYSTEM_PROMPT` |
| 提示词里包含哪些仓库信息、模板与聊天内容 | `issue/agent.py` 的 `_build_prompt()` |
| 模板骨架怎么拼 | `issue/templates.py` 的 `_form_skeleton()`（YAML 表单）与 `parse_markdown_template()` |
| 仓库没有模板时的兜底结构 | `issue/templates.py` 的 `GENERIC_TEMPLATE` |
| 草稿预览长什么样 | `issue/draft.py` 的 `format_preview()` |
| 截图怎么上传（附件接口 / 分支） | `issue/assets.py` 的 `upload()` / `_upload_attachments()` / `_commit_batch()` |
| 分支模式下截图提交到哪个分支、目录怎么排 | `issue/assets.py` 的 `_asset_prefix()` / `_branch_name()` |
| 从哪里收集引用、转发与图片 | `issue/context.py` 的 `ChatContextCollector.collect()` |
